## Version française

Cherchez une icône de moto-taxi dans les grandes bibliothèques d'icônes.
Ou de tontine. Ou de plantain.

Vous trouverez des taxis jaunes, des tasses de latte et des maisons à cheminée. Pas le quotidien de nos utilisateurs.

Alors nous l'avons dessiné.

Afroicons est maintenant disponible sur npm, en open source.

→ 150 icônes culturelles : paysages, faune, instruments, symboles adinkra, cuisine, vie quotidienne, architecture
→ 108 icônes d'interface compatibles Lucide : on change une ligne d'import, et toute l'app passe en Afroicons
→ Pour React, Angular ou en SVG, en français et en anglais
→ Licence MIT : gratuite, même pour un usage commercial

Ce qui nous tient le plus à cœur, ce sont les métaphores.
Dans une app Afroicons, la caisse est un panier tressé. L'argent, un cauri. La livraison, une moto. L'hôtel, un lit sous sa moustiquaire.
Des détails, oui. Mais ce sont eux qui disent à un utilisateur : cette app a été pensée pour vous.

Et la bibliothèque n'est pas finie. Elle se construit avec vous : proposez l'icône qui vous manque, votez pour celles des autres, et les plus demandées entrent dans la prochaine version. Designers, développeurs, passionnés de culture : vos dessins, votre code et vos savoirs sont les bienvenus.

Alors, quelle icône devrions-nous dessiner ensuite ? 👇

Un projet de THAFAM HOLDING SARL, fait avec soin à Yaoundé 🇨🇲, avec le soutien de NAFA ERP.

#OpenSource #DesignSystem #React #Angular #TechAfrique

## English version

Look for a moto-taxi icon in the big icon libraries.
Or a tontine. Or a plantain.

You'll find yellow cabs, latte cups and chimney houses. Not our users' everyday life.

So we drew it.

Afroicons is now on npm, open source.

→ 150 cultural icons: landscapes, wildlife, instruments, adinkra symbols, food, daily life, architecture
→ 108 Lucide-compatible interface icons: change one import line and your whole app switches to Afroicons
→ For React, Angular or plain SVG, in French and English
→ MIT licence: free, commercial use included

What we care about most are the metaphors.
In an Afroicons app, checkout is a woven basket. Money is a cowrie shell. Delivery is a motorbike. A hotel is a bed under its mosquito net.
Small details, yes. But they are what tells users: this app was made for you.

And the library isn't finished. It grows with you: suggest the icon you're missing, vote for others' ideas, and the most wanted make it into the next release. Designers, developers, culture lovers: your drawings, code and knowledge are welcome.

So, which icon should we draw next? 👇

A THAFAM HOLDING SARL project, made with care in Yaoundé 🇨🇲, supported by NAFA ERP.

## Premier commentaire à épingler · Pinned first comment

**FR**

🔗 Le site, pour explorer, personnaliser et télécharger les icônes : https://afroicons.org
💻 Le code source, pour contribuer : https://github.com/cybexai/afroicons

Pour l'installer :
• React : npm install afroicons-react
• Angular : npm install afroicons-angular
• Pour remplacer Lucide : npm install afroicons-ui, puis remplacer « lucide-react » par « afroicons-ui » dans vos imports
• En SVG seuls : npm install afroicons
