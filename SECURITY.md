# Sécurité

Afroicons publie des SVG, des paquets npm (`afroicons`, `afroicons-react`, `afroicons-ui`) et le site afroicons.org.

## Signaler une faille

**N'ouvrez pas de ticket public.** Utilisez le signalement privé de GitHub : onglet *Security* du dépôt → *Report a vulnerability*. À défaut, écrivez à **contact@afroicons.org**.

Indiquez si possible le paquet ou la page concernés, la version, les étapes pour reproduire et l'impact. Nous accusons réception sous 5 jours ouvrés et tenons la personne informée jusqu'à la correction.

## Versions suivies

Seule la dernière version publiée de chaque paquet reçoit des correctifs de sécurité.

---

*English:* please report vulnerabilities privately through GitHub's *Security → Report a vulnerability*, or at contact@afroicons.org. Do not open a public issue. Only the latest release of each package is supported.
